# About

EldenNet lets characters of the game hold a free conversation with you, in their own voice, written by an AI model you
choose. It reads the game and never changes it, and works only offline, alone in your own world.

System › Status › Compatibility says whether this version of EldenNet supports your game's build, and which GraceUI it
needs.

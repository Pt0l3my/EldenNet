# Probe records

This folder holds our own records of the derivation rounds (O89; ARCH §6.3, §13): for each file a round returns from
the owner's PC, a short reviewed note in our own words, with the run's date, the SHA-256 of the tool, the leads and the
returned file, the counts that matter, what each finding meant and what was fixed before the next round; and, once R1
has confirmed them, the evidence files that `gal/patterns.toml` and the layouts cite as `<build>.json`. Nothing here
holds bytes, patterns or text of the game, paths, or anything of the owner's: numbers, our own labels and our own
words only.
